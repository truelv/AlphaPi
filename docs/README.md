## 建议阅读路径

**刚拿到板子，想连上它：**

1. `AlphaPi_实机调试指南.md` §1–§2（连不上、界面全黑、怎么进 REPL）
2. `AlphaPi_实机调试指南.md` §3–§5（能干什么、常用命令）

**想搞清楚手上的板子是什么：**

1. `../firmware/README.md`（代际识别）
2. 对应设备的实机分析报告（循迹小车 / 游戏机）

**想写自己的程序：**

1. `AlphaPi_实机调试指南.md` §7（上传与生效流程）
2. `../projects/breakout/README.md`（可复用的完整示例）
3. 对应实机报告的 API 章节

**想研究固件本身：**

1. `AlphaPi_项目分析文档.md`（历史代际的完整 API 还原）
2. `../firmware/*/disasm/`（反汇编文本）

## 每份文档开头的「当前固件与运行状态」

两份实机报告开头都有这一节，记录了采集时板上跑的**固件版本与自启程序**。
板子状态会变，**引用报告数据前建议先核对这一节**。
