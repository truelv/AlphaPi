# host —— 两套遥控端（网页版 / 手柄版）

两条路线**互不影响**：各自的文件、依赖、部署方式都在自己目录里；可以只装一套，也可以都装
（但**同一时间只用一套**）。

| | [`web/`](web/) 网页版 | [`pad/`](pad/) 手柄版 |
|---|---|---|
| 跑在 | PC / 树莓派（Windows、Linux 均可） | 同族手柄板（ESP32-S3 + 摇杆 + ST7735 屏） |
| 用户操作 | 手机 / 电脑浏览器 | 手柄摇杆 + 4 个按键 |
| 依赖 | **无**（纯 Python 标准库） | 手柄板自带 `controlBoardAlphaPiOne` / `remoteControlSensorOne` |
| 额外硬件 | 一台常开的 PC 或树莓派 | 一块手柄板（USB 供电即可，可拔线玩） |
| 在线状态 | 网页顶部三色 + 心跳延迟 + 最后指令 | 手柄屏上显示小车在线 / 速度 / 方向 |
| 一键部署 | `web/deploy/deploy_pi.py`（→ 树莓派） | `pad/deploy_pad.py`（→ COM11 手柄板） |
| 适合 | 想用手机控、想常开、多人围观 | 拿起来就玩、不占用电脑、摇杆手感最好 |

两者发送的是**完全相同的 UDP 协议**（见 [`../README.md`](../README.md#通信协议两套遥控端完全一致)），所以：

- 小车端固件（[`../board/`](../board/)）**只装一次**，两套都能用；
- 切换遥控端**不用改任何代码**——换个设备发指令即可。

## ⚠️ 务必注意

**同一时间只用一种遥控端。** 两边都往 `UDP :1000` 发指令，同时用会互相抢控制权（车会"抽风"）。
要换另一套时，先停掉当前的（关掉网页服务 / 断开手柄电源）。
