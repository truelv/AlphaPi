# board_dump —— 从板子上导出的文件

本目录存放**直接从板子（ESP32-S3）导出/派生**的原始资料，不做二次整理，仅作证据留存。

| 内容 | 说明 |
|---|---|
| `*.asm` | 对板上 `.mpy` 的反汇编文本（mpy-tool 产物），用于还原 API/引脚/寄存器 |
| `*_cap.txt` | 串口原始捕获（REPL 响应、UDP 自发自收等） |
| `*_out.txt` | 从捕获中提取出的有效输出 |
| `dumped/` | 从板上分块取回并解码的 `.mpy` 原件 |
| `game/` | 从板上导出的一组示例固件文件（另一版本） |
| `controlBoardAlphaPiOne.mpy` / `max30102.mpy.txt` 等 | 单个模块的原件/反汇编 |

- **固件的"正式备份"**放在 [`../firmware/`](../firmware/)（按版本归档），本目录是**探查过程中的原始产物**。
- 生成/处理这些文件的工具在 [`../tools/`](../tools/)。
- 结论性内容（引脚表、寄存器表、经验）已沉淀到 [`../docs/`](../docs/)。
